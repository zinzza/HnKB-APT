한 줄로 설치하세요.

GUI 데스크톱 없이 동작하는 Raspberry Pi ARM64용 HnKB 공식 APT 저장소입니다. 패키지는 서명되어 있으며 GitHub 계정 없이 설치하고 업데이트할 수 있습니다.

stable 최신 버전 확인 중… arm64

01 / 저장소 등록

처음 한 번만 실행합니다

라즈베리파이 터미널에서 아래 명령을 순서대로 실행하세요.

서명 키 설치 
sudo apt update
sudo apt install --yes ca-certificates curl
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://zinzza.github.io/HnKB-APT/hnkb-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/hnkb-archive-keyring.gpg >/dev/null
sudo chmod 0644 /etc/apt/keyrings/hnkb-archive-keyring.gpg
APT 저장소 등록 
printf '%s\n' \
  'Types: deb' \
  'URIs: https://zinzza.github.io/HnKB-APT/' \
  'Suites: stable' \
  'Components: main' \
  'Architectures: arm64' \
  'Signed-By: /etc/apt/keyrings/hnkb-archive-keyring.gpg' \
  | sudo tee /etc/apt/sources.list.d/hnkb.sources >/dev/null

02 / 설치

HnKB를 설치합니다

패키지 설치 
sudo apt update
sudo apt install hnkb

설치 후에는 kbwp 명령으로 실행할 수 있습니다.

03 / 업데이트

평소 업데이트

다른 Raspberry Pi OS 패키지와 같은 방식으로 업데이트됩니다.

sudo apt update
sudo apt upgrade

hnkb-update만 실행해도 HnKB 업데이트를 확인하고 설치합니다.

APT 저장소를 제거하려면 
sudo rm /etc/apt/sources.list.d/hnkb.sources
sudo rm /etc/apt/keyrings/hnkb-archive-keyring.gpg
sudo apt update

HnKB 프로그램까지 제거하려면 sudo apt remove hnkb를 추가로 실행하세요.
