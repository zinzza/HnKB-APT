# HnKB APT Archive

Raspberry Pi OS/Debian arm64용 HnKB 공개 APT 저장소입니다.

사용자 설치 안내는 <https://zinzza.github.io/HnKB-APT/>에서 제공합니다.
패키지와 저장소 메타데이터는 비공개 `zinzza/HnKB` 저장소의 릴리스
워크플로가 생성하며, 모든 APT 메타데이터는 전용 OpenPGP 키로 서명합니다.

## 저장소 정보

- Suite/Codename: `stable`
- Component: `main`
- Architecture: `arm64`
- Archive key fingerprint: `72A6 F7F8 1413 78C6 706B 4907 E08A BF48 3207 559B`

이 저장소에는 배포에 필요한 바이너리와 메타데이터만 포함하며 HnKB 소스
코드는 포함하지 않습니다.
